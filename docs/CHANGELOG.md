# Changelog

## 1.0.0 — 2026-10-21

首个开源版本。

### 功能

- 访问码首页（多访问码、可停用/删除、会话级 Cookie + 12 小时）
- 预览端：人物列表按世代分组、树状图（全局 / 聚焦三代）、公告栏
- 管理端：人物 CRUD、父子关系、世代自动计算、乐观锁、防环
- 回收站：30 天、单击删除 + 10 秒撤销、彻底删除需输入 DELETE
- 审计日志：分页 50/页、关键词/动作/日期筛选、保留一年、删除后保留姓名快照
- 账号：admin/user 两级、新增/改名/角色/停用/重置密码/删除
- 站点设置：标题、简介、印章/Logo、公告
- 数据备份：账号 JSON、族谱 JSON、数据库 `.dump` 下载；JSON 覆盖恢复
- 每日 03:00 自动备份，保留 7 份；审计滚动清理
- 响应式：可收起侧边栏、手机抽屉、表格横向滚动

### 安全

- Next.js 15.5.28 / React 19.0.1，修复 2026 年 RSC DoS 系列公告
- scrypt 密码哈希、HttpOnly/Secure Cookie、登录/访问码限流
- 同站 CSRF 校验、请求体上限、scrypt 并发限制
- 备份目录 750 / 文件 640、sha256、符号链接拒绝
- 账号恢复删除备份外账号；导入严格校验
- 页面 307 + API 403 双重鉴权
- HTTPS 部署说明（本地 CA / 反代）

### 工程

- Docker Compose 五服务（HTTPS 时六服务）；多阶段镜像；standalone 输出
- 发布镜像包 + `compose.release.yaml`
- GitHub Actions：CI（`npm ci` + `next build`）+ tag 自动构建/上传 Release 镜像包
